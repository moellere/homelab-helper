## Proposed change

Adds a `google_weather.get_minute_forecast` entity service to the Google Weather integration, returning the minute-by-minute precipitation nowcast (up to 6 hours) from the experimental [minute forecast endpoint](https://developers.google.com/maps/documentation/weather/minute-forecast).

Design notes:

- Mirrors the existing `openweathermap.get_minute_forecast` pattern: entity service on the weather entity, `SupportsResponse.ONLY`.
- **On-demand only — no coordinator, no polling.** The Weather API free tier is 10,000 calls/month and the integration already spends ~4,400/month per location; a service call costs one request only when an automation/template asks for it.
- Errors are raised as `HomeAssistantError` with a translated message (`minute_forecast_error`).
- `quality_scale.yaml`: `action-setup` stays exempt (entity services are registered in the platform), `action-exceptions` and `docs-actions` become `done`.
- New library API: `python-google-weather-api` gains `async_get_minute_forecast` (library PR: LINK-TO-LIBRARY-PR).
